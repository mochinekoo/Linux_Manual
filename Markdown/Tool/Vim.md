# 概要
* テキストエディタのvimについての説明です。

# 編集モード
* 小文字 i：カーソルの位置から
* 大文字 I：カーソルの行の頭から

# 操作
* control+F：1画面次へ
* control+b：1画面前へ
* 大文字 G：ファイルの最後の行に
* 小文字 gを2回：ファイルの先頭行へ
* 数字キー と 大文字 G：ファイルの先頭から、押した数字キー行目に飛ぶ（例：10 G と打つと、ファイルの先頭から10行目の位置に飛ぶ）
* :w ：上書き保存
* :q ：ファイルに変更がなかった場合に、保存せず終了（変更があると、:q は実行できず、:q! を実行する）
*  :q!　：ファイルに変更はあった時に、保存せず終了
*  :wq ：保存して終了
*  :w　ファイル名 ：　指定したファイル名で保存する
