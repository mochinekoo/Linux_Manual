# 概要
* ファイルやディレクトリをコピーするコマンドについての説明です。

# コマンド
* cp <コピーしたいファイル> <コピー先>

# コマンドの例
* aa.txt というファイルを、bb.txt としてコピーする場合
```shell
cp aa.txt bb.txt 
```
* aa というディレクトリの中身を、bb ディレクトリとしてコピーする場合
```shell
cp -r aa bb
```

# オプション
| オプション | 内容           |
|-------|--------------|
| -i    | 上書きするかを確認する。 |
| -r | ディレクトリごとコピーする |
